# Changelog

All notable changes to this project will be documented in this file.

## 0.0.2 - 2026-10-12

### Changed

- Raise PHP requirement to `^8.2`
- Add Laravel 12 support (`illuminate/*` `^11.0|^12.0`)
- Update development dependencies for Laravel 11/12 testbench

## 0.0.1 - 2026-06-12

### Added

- Initial release
- Laravel service provider and auto-discovery
- Configurable system integration for host applications
- Scheduled maintenance tasks
- Runtime fallback for environments without server cron
- File-based state storage
